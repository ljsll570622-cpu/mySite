Definition & Criteria

什麼是校園霸凌？

必須同時符合特定要件，才構成法律與準則定義之校園霸凌行為。

01

行為具備惡意

指個人或集體持續蓄意欺負他人，包含言語、肢體、網路或關係上的故意傷害與排除。

02

權力不對等

雙方在年齡、體型、人數、社會地位或同儕影響力上存在不對等，導致被害人難以抵抗。

03

造成身心痛苦

導致被害人產生生理或心理上的嚴重負面影響，如恐懼、憂鬱、社交退縮或人格受損。

Bullying Types

常見的校園霸凌類型

霸凌不只是肢體衝突，生活中各種隱形傷害同樣不可忽視。

🥊

肢體霸凌

推擠、毆打、踹踢、搶奪或毀損個人物品等直接的身體傷害與暴力行為。

🗣️

言語霸凌

用言語嘲弄、辱罵、取難聽綽號、恐嚇、威脅或惡意中傷。

👥

關係霸凌

散布謠言中傷、排擠、杯葛、孤立他人，故意不讓其參與群體活動。

💻

網路霸凌

透過社群媒體、通訊軟體張貼有害言論、公開私密照片、惡意留言與肉搜。

SOP & Flow

學校處理與通報流程

嚴謹、保密且具保護機制的調查與處理程序。

1
Step 01

發現與通報

師長、學生或家長發現疑似霸凌事件時，應立即向學校學務處或輔導室通報。

2
Step 02

受理與訪查

學校受理後成立防制霸凌因應小組，於法定時間內啟動訪談與事實釐清。

3
Step 03

審議與輔導

確認霸凌事實後，依情節輕重給予行為人輔導或處分，並對被害人提供心理諮商與保護措施。

4
Step 04

追蹤與結案

持續追蹤輔導成效，確保校園安全與雙方身心健全發展。

Rights & Appeal

當事人權益與申訴管道

維護每一位學生的基本權益，不因檢舉或通報遭受不公平對待。

🛡️

檢舉人與被害人保護

  • 保密義務： 學校對於通報人、被害人及關係人之身分資料應予保密，嚴禁洩漏。
  • 免受報復： 不得因提出檢舉或協助調查而遭受校內不利之處置或差別待遇。
  • 心理支持： 被害人得優先申請輔導資源介入，減輕心理創傷。
⚖️

申訴與救濟途徑

  • 不服處置申訴： 若對調查結果或處理措施有異議，得於法定期限內向學校學生申訴評議委員會提出申訴。
  • 主管機關協助： 若學校處理不周，可向各縣市教育局處或教育部防制校園霸凌專線反映。

💡 Google Apps Script (GAS) 後端設定教學：

  1. 建立一個 Google 試算表，第一列欄位依序設為：時間戳記、身分性質、狀況簡述、聯絡方式。
  2. 點選「擴充功能」>「Apps Script」，貼入下方附帶 `@OnlyCurrentDoc` 標籤的程式碼。
  3. 部署為「網頁應用程式」，存取權限設為「任何人 (Anyone)」，並將產生的網址貼在上方輸入框中。
/**
 * @OnlyCurrentDoc
 */
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    var timestamp = new Date();
    var identity = data.identity || "";
    var content = data.content || "";
    var contact = data.contact || "";
    
    sheet.appendRow([timestamp, identity, content, contact]);
    
    return ContentService.createTextOutput(JSON.stringify({"status": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

一、 法規核心概述

為落實高級中等以下學校教師解聘、不續聘、停聘或資遣之處理機制，教育部依據《教師法》相關授權訂定本辦法。其核心目的在於建立客觀、公正、公開之處理程序，兼顧學生受教權益與教師工作權。

當學校接獲檢舉或發現教師涉有教學不力、不能勝任工作、違反品德或相關法規時，即應依本辦法啟動「校事會議」（學校事件處理會議），並依案件性質組成調查小組或審查小組，進行事實認定與處理。

二、 適用處理事由與分類

依據教師法及本辦法，學校得針對下列具體態樣進行調查與處理：

01

教學不力或不能勝任

教師教學品質低落、無法達成教學目標、經輔導仍未改善，或確有其他不能勝任工作之具體事實者。

教師法第14條 / 第15條
02

消极資格與重大違法

犯性侵害犯罪防治法、防制霸凌、吸毒、詐欺等經判刑確定，或有欺瞞資格、行為不檢有損師道情節重大者。

教師法第14條第1項
03

體罰與霸凌行為

霸凌學生情節重大，或對學生有嚴重身心虐待、體罰、霸凌或其他不當管教行為，情節重大須予解聘者。

教育基本法 / 教師法規範

三、 校事會議標準處理程序

點擊下方各階段按鈕，快速檢視學校處理案件的四個關鍵步驟：

Step 1

學校接獲檢舉或事件發生，召開校事會議

學校於知悉教師涉有應予解聘、不續聘、停聘或資遣之情事後，應於法定期限內組成「學校事件處理會議」（校事會議）。校事會議應審議是否受理，若受理則決定組成調查小組或直接依規定處理。

重點提醒：校事會議成員需符合性別比例與專業公正要求，避免球員兼裁判。
Step 2

組成調查小組進行事實調查與訪談

調查小組由校内外專家學者或具調查專業素養之人員擔任（如涉及性平或霸凌另依專法）。調查期間應給予雙方當事人充分陳述意見之機會，並製作調查報告提交校事會議審議。

重點提醒：調查過程應嚴守保密義務，保護檢舉人與被調查人隱私。
Step 3

移送教師評審委員會（教評會）審議

校事會議確認調查屬實後，依情節輕重將案件移送教師評審委員會（教評會）審議。教評會應依調查報告認定事實，並作成解聘、不續聘、停聘或資遣等適當之法定處分決議。

重點提醒：教評會審議時，應給予當事人書面或到場陳述意見之機會。
Step 4

報請主管機關核准並發布執行

學校教評會作成決議後，應於法定期間內報請主管機關（教育部或地方政府教育局）核准。經主管機關核准後，學校應正式發布處分書，並依法辦理後續解聘、不續聘、停聘或資遣作業。

重點提醒：處分書應附具理由及教示救濟期限，保障教師後續行政救濟權利。

四、 當事人權益保障與救濟途徑

程序防護權益

  • 陳述意見權：調查及教評會審議時，教師均享有充分書面或口頭陳述意見權利。
  • 律師陪同協助：接受訪談或陳述時，得委任並偕同律師或專業代理人到場。
  • 迴避制度：調查小組或教評會成員若與當事人有利害關係，應依法主動或申請迴避。

行政救濟途徑

  • 教師申訴：不服學校處分者，得於收到處分書次日起 30 日內，向學校所在地之直轄市、縣（市）教師申訴評議委員會提起申訴。
  • 行政訴訟：對申訴決定不服或再申訴遭駁回者，得依法向管轄之行政法院提起行政訴訟，尋求司法救濟。

五、 常見問答 (FAQ)

針對校事會議實務運作常見的疑問提供解答：

校事會議主要負責「事件之受理、啟動、組成調查小組與事實調查程序」；而教評會則依據調查結果，針對教師身分（解聘、不續聘、停聘、資遣）做出人事處分決議。兩者任務分工不同，相輔相成。
為確保調查之客觀與公信力，依規定調查小組成員應以外聘專家學者為主，且須具備相關事件調查專業素養，避免球員兼裁判或遭質疑偏頗。
依本辦法及實務規範，調查訪談過程多由學校製作正式訪談紀錄，受訪人得於確認筆錄內容無誤後簽名。若欲自行錄音或錄影，通常須徵得調查小組及參與人員同意，以維護個人隱私與程序順暢。

請在您的 Google 試算表內點選「擴充功能」>「Apps Script」，並更新為下列程式碼（包含時間戳記、姓名、聯絡電話與事情略述欄位對應）：

/**
 * @OnlyCurrentDoc
 */
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // 解析前端送來的 JSON 資料
    var data = JSON.parse(e.postData.contents);
    var name = data.name || '';
    var phone = data.phone || '';
    var summary = data.summary || '';
    var timestamp = new Date();
    
    // 欄位對應寫入試算表：時間戳記、姓名、聯絡電話、事情略述
    sheet.appendRow([timestamp, name, phone, summary]);
    
    return ContentService
      .createTextOutput(JSON.stringify({ "status": "success", "message": "已成功寫入試算表" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
